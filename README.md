# .github

Default community health files for every public repository under `coolbress`
(`plinth`, `plinth-template`, `plinth-lab`, and any future one).

GitHub applies these automatically to a repository that does not carry its own copy:

| File | Applies to |
|---|---|
| `SECURITY.md` | how to report a vulnerability, what is in scope |
| `CODE_OF_CONDUCT.md` | Contributor Covenant 3.0 |
| `PULL_REQUEST_TEMPLATE.md` | what a pull request body contains |
| `.github/ISSUE_TEMPLATE/` | bug and feature forms |

A repository that needs a different version adds its own file; that file wins.
`LICENSE` is not inherited, so each repository ships its own. `CONTRIBUTING.md` is
deliberately per repository too: build, test and PR-flow instructions differ, and a
generic one would be a stub.

`SECURITY.md` points at GitHub's private vulnerability reporting, which each repository
must enable in its settings; the file alone does not turn it on.

These files are for the `coolbress` repositories themselves. Projects generated by
`plinth-template` live in other accounts and receive their own copies from the template.
